What this project is

Program Command is the EWU Design program's scheduling, workload, and capacity-planning surface. Vanilla JS frontend, Supabase (Postgres) for persistence, Chart.js for visuals. npm run build runs Vite and passed in the 2026-09-14 audit, but production does not use it: the deploy publishes the repository root, not dist/, and a dist/ deploy would break Enrollment. Production is a static GitHub Pages site reading a public Supabase project; edits are gated by a server-side editor allowlist.
